# Explainer Video Generator

中文名称：科普讲解视频生成器  
当前版本：`1.0.0`

`explainer-video-generator` 是一个面向 Agent 的完整口播科普视频制作 Skill。它以已经完成剪辑的口播 MP4、对应 MP3、口播文稿和视频配置文件为输入，使用 HyperFrames 制作时间轴驱动的科普动画、人物全屏与画中画切换、可选整句字幕、可选素材与声音增强，并最终合成完整成片。

## 核心特点

- 不修改用户已经完成剪辑的口播视频内容和节奏。
- 使用 MP3 作为标准口播音轨，MP4 在合成中静音使用。
- 人物全程可见，支持人物全屏、局部覆盖动效和圆形画中画。
- 动画严格依据真实口播内容和时间轴生成。
- 默认支持整句字幕，也可关闭字幕或扩展其他字幕模式。
- 外部素材、背景音乐和音效分别独立启停。
- 使用 HyperFrames 作为唯一动画与合成框架。
- 通过双轮对抗式审查、用户审批门和技术质检控制质量。
- 项目状态、Session、审批、返工和交付物均可追溯、可恢复。

## Session 架构

一个完整项目包含：

- 1个项目经理 Session：负责全局状态、调度、验收、变更影响和阶段放行。
- 15个串行阶段 Session：P00–P14，每个阶段拥有独立上下文和结构化交接包。

Session 默认命名：

```text
EVG-PM-<项目简称>
EVG-P00-<项目简称>
EVG-P01-<项目简称>
...
EVG-P14-<项目简称>
```

阶段 Session 按需创建。只有前一阶段通过用户门禁和项目经理验收后，才启动下一阶段。

## 十五个制作阶段

| 阶段 | 名称 |
|---|---|
| P00 | 项目初始化与输入契约 |
| P01 | 媒体校验与同步 |
| P02 | 转录校对与主时间轴 |
| P03 | 事实与内容锁定 |
| P04 | 动画筛选与人物布局 |
| P05 | 导演脚本与视觉系统 |
| P06 | 制作前对抗式审查 |
| P07 | 三页静态审阅图 |
| P08 | 真实素材集成样片 |
| P09 | 全场景与关键帧实现 |
| P10 | 全片低质量初稿 |
| P11 | 受控精修与回归 |

完整输入、动作、交付物和验收标准见 [`references/phase-specifications.md`](references/phase-specifications.md)。

## 用户互动和提交授权

P00、P04、P05、P07、P08、P10、P14 必须在对应阶段 Session 中与用户讨论。

文件批注、问答、内容认可、原则同意或附条件批准都不等于授权提交。阶段 Session 必须先处理全部批注、附加要求和问答，冻结最终版本并确认未决事项为零，然后单独询问用户是否允许提交项目经理。

只有用户明确表示“可以提交项目经理”，并记录 `SUBMISSION_AUTHORIZED` 后，阶段才能提交。授权后如果继续修改文件、产生新版本或出现新问题，原授权自动失效。

## 必需输入

- 已完成剪辑的口播 MP4。
- 与 MP4 节目音频一致的 MP3。
- 口播文稿或校正转录稿来源。
- 视频配置文件，包括画幅、帧率、安全区和平台遮挡区。

可选输入包括品牌参考、事实依据、外部图片或视频素材、背景音乐和音效。

## 环境要求

- Python 3.10 或更高版本。
- Node.js 22 或更高版本。
- HyperFrames CLI。
- FFmpeg 与 FFprobe。
- 可供 HyperFrames 使用的 Chrome 或 Chromium。
- 需要自动转录时安装可用的 Whisper 后端。

本仓库自身不包含运行时、虚拟环境、媒体文件或第三方二进制文件。

## 安装

将仓库克隆到 Codex Skill 目录：

```text
git clone https://github.com/jasonaisg/explainer-video-generator.git ~/.codex/skills/explainer-video-generator
```

也可以克隆到其他 Agent 能够读取 Skill 的目录。确保 Agent 能发现根目录中的 `SKILL.md`。

## 启动示例

最小提示词：


输入已准备好时：

```text
请使用 $explainer-video-generator 启动一个新的科普讲解视频项目，并担任项目经理。

项目根目录：<绝对路径>
口播 MP4：<绝对路径>
对应 MP3：<绝对路径>
```

## 关键脚本

- `projectctl.py`：初始化项目、登记 Session、阶段调度、审批与提交授权。
- `validate_project.py`：校验项目目录、状态、交付物哈希和门禁记录。
- `probe_media.py`：使用 FFprobe 检查 MP4、MP3 和时长差异。
- `validate_timeline.py`：校验转录、字幕和人物布局时间轴。
- `build_manifest.py`：生成带 SHA-256 的阶段交付清单。

## 视频编码策略

Skill 不强制输入或最终输出必须使用 H.264。输入可以是 H.265/HEVC；P01 会检查 FFmpeg、Chrome 和 HyperFrames 的实际兼容性。如果浏览器不能稳定解码原文件，应保留原文件并生成不改变内容和时间轴的技术代理文件。

最终编码依据用户配置和目标发布平台决定。H.264 通常兼容性更高，H.265 通常压缩效率更高。需要透明通道的独立素材应使用支持 Alpha 的格式，而不是普通 H.264 MP4。

## 版本规则

本项目采用[语义化版本](https://semver.org/lang/zh-CN/)：

- 主版本：工作流或项目数据结构发生不兼容变化。
- 次版本：增加向后兼容的能力、阶段机制或工具。
- 修订版本：修复缺陷、改进文档或进行兼容性调整。

`VERSION` 是版本号的权威来源。正式版本建议同时创建同名 Git 标签，例如 `v1.0.0`。
